===========
Multi Search
===========

Search multiple records at once in any Odoo view — by pasting from Excel or using the ``{ }`` syntax.

Features
========

* **Paste from Excel** — Copy a column of references from a spreadsheet and paste directly into the search bar. All records are found at once.
* **Curly brace syntax** — Type ``{REF001 REF002 REF003}`` and press Enter to search multiple values separated by spaces.
* **Works everywhere** — Compatible with any search field available in the dropdown: Internal Reference, Product Name, Barcode, Order Number, Partner Name, and more.
* **Works on any view** — Products, Sales Orders, Purchase Orders, Contacts, Inventory moves, and any other Odoo list view.
* **OR logic** — Results include records matching any of the provided values.
* **No configuration needed** — Install and use immediately.

Usage
=====

**Method 1 — Paste from Excel:**

1. In your spreadsheet, select a column of references (one per row)
2. Copy (Ctrl+C)
3. Click the Odoo search bar
4. Paste (Ctrl+V)
5. All matching records appear instantly

**Method 2 — Curly brace syntax:**

1. Click the Odoo search bar
2. Type ``{REF001 REF002 REF003}`` (values separated by spaces)
3. Select the search field from the dropdown (e.g. Internal Reference)
4. Press Enter
5. All matching records appear instantly

Compatibility
=============

* Odoo 18 (Community & Enterprise)
* Works with all standard and custom search fields
