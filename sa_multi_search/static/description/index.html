How it works

Two simple methods

Method 1 -- Paste from Excel
Your Excel file

Select your reference column in Excel and copy it (Ctrl+C)

1

Select your references in Excel

Highlight the column containing your references -- one per row. Copy with Ctrl+C.
2

Paste into the Odoo search bar

Click the search bar in any Odoo view and paste with Ctrl+V. The module instantly detects multiple values.
3

All matching records appear instantly

Results are displayed immediately -- all references found in a single search with OR logic.
Result in Odoo

All 10 products found instantly from the pasted references

Method 2 -- Curly brace syntax
1

Type your references

In the search bar, type { TBL-001 CHR-001 PRZ-001 } with spaces between each value.
2

Select the search field

Choose from the dropdown which field to search on -- Internal Reference, Name, Barcode, etc.
3

Press Enter -- done

All matching records are displayed with OR logic, exactly as if you had searched each value individually.
