All matching records appear instantly

Method 2 -- Curly brace syntax
1

Type your references

In the search bar, type { TBL-001 CHR-001 PRZ-001 } with spaces between each value.
2

Select the search field

Choose from the dropdown which field to search on -- Internal Reference, Name, Barcode, etc.
3

Press Enter -- done

All matching records are displayed with OR logic, exactly as if you had searched each value individually.
